# Tableau workbook and refresh

Open dashboard/Circle_Week.twbx in Tableau Desktop or Tableau Public. The ZIP
contains the .twb and all four CSV sources under Data/. No local absolute paths,
extensions, parameter actions or computed-sort XML elements are used.

The workbook contains four sheets and a 1300 × 900 dashboard: weekly revenue,
category dollar effects, regional dollar effects and cost-sensitivity contribution.
Every CSV is generated by the same validated pipeline. Aggregation is AVG for
precomputed effect measures to avoid summing confidence limits. The category and
regional CSVs also contain CI bounds and adjusted p-values for optional tooltips.

The standalone .twb expects the adjacent Data/ folder. If Tableau asks for a file,
choose the matching CSV from that folder. Re-run `python -m src.pipeline`, reopen
the regenerated .twbx and use Data → Refresh if working on a saved copy. Do not
manually change generated values. In Tableau Public, create an extract if prompted
before publishing. Publishing requires the user's signed-in Tableau environment.

Build/review steps:
1. Weekly revenue: week_start_date on Columns, AVG(revenue) on Rows, test_group
   on Color; line marks. Dates are ISO strings in this compact workbook.
2. Category effects: category on Rows, AVG(effect_usd_per_store_week) on Columns.
   Add ci_low/ci_high and holm_p_value to Tooltip. Only placebo tests use Holm.
3. Regional effects: region on Rows, AVG(effect_usd_per_store_week) on Columns.
   Include n_stores and Holm p-values in tooltips; call comparisons exploratory.
4. Cost scenarios: scenario on Rows, AVG(incremental_contribution_usd) on Columns.
   Display assumed margin, additional promotion cost and fixed cost in tooltips.
5. Keep a synthetic-data note in the dashboard title/caption. Explain that revenue
   estimates are not actual Target sales, and scenarios are not profit forecasts.

**Verification status:** ZIP integrity, XML parsing, column references and embedded
CSV consistency are checked automatically. Native Tableau opening, rendering,
extract creation and publication cannot be verified in this Linux environment.
The offline HTML controls are DOM-tested and the PNG is visually inspected. Do not claim
that XML parsing establishes Tableau-version compatibility.
